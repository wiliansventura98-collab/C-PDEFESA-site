# C-PDEFESA: site da base de concursos e pós-doc

Site: <https://wiliansventura98-collab.github.io/C-PDEFESA-site/>

Este repositório tem **só o código** do painel (HTML/JS e malha dos estados). Nenhum dado pessoal fica aqui.

A base fica no repositório **privado** `C-PDEFESA`, no arquivo `data/base.json`. Ao abrir o site, entre com uma chave de acesso do GitHub (*fine-grained personal access token*) com:

- **Repository access:** Only select repositories → `C-PDEFESA`
- **Permissions → Contents:** Read and write

A chave fica guardada só no navegador. Cada alteração feita no site é salva como um commit no repositório privado.

Créditos da malha: IBGE (via tbrugz/geodata-br).
